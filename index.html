Pipeline

  
From Microsoft 365 to an answer

  
The layer your AI teacher and your document assistant are waiting for, deployed on your own Jelastic and handed over with documentation.

  

    
  

  

    
1
Sync with zero duplicates
Microsoft Graph delta returns new, changed and deleted items. We track by item id, not by name, so a renamed folder never duplicates. A single delta batch can mention one file several times and only the last record counts. When a token expires Graph answers 410 and we run a clean resync. A deleted file is also removed from pgvector, so the assistant never answers from a document you removed.

    
2
Two level OCR, by measurement
Clean pages stay on local OCR, which you saw read Kazakh at 96.3 above. Tables, stamps and weak scans go to a vision model. Published research on Kazakh scripts shows blanket LLM correction of Cyrillic Kazakh adds little and can hallucinate, so official text is never rewritten silently. DOCX files and PDFs that already carry a text layer skip OCR completely, which is faster and exact. Pages the gate cannot trust go to Review Required, for human eyes.

    
3
Structure into pgvector
Headings, sections, pages and tables survive extraction, then the text splits into chunks with embeddings in PostgreSQL with pgvector. A question returns the exact passage with its page and section. That is the loop your AI teacher needs, a syllabus goes into a folder and becomes answerable knowledge without anyone uploading it by hand.

    
4
Deploys on your Jelastic
The stock PostgreSQL template does not include pgvector, so we ship a prepared image and a one click JPS manifest. API, workers and the database run as separate layers, and the OCR worker layer scales out when a large batch arrives. Your team can redeploy the whole thing without us.

Corporate data security

  
Read only, least privilege, your consent

  

    
Read only scopes
The connection asks only for Files.Read.All and Sites.Read.All. Nothing is ever written back to your OneDrive or SharePoint.

    
Your admin approves
Access starts only after your own tenant administrator grants consent, and can be revoked in your admin center at any minute.

    
Data stays with you
Documents, extracted text and embeddings live inside your Jelastic environment. The LLM provider is a config switch and can point to a provider you approve.

    
This page asks for nothing
The live test above runs inside your browser. No account, no upload, no tracking. We request no access at this stage.
